# OVPN30

OpenVPN Android client based on the GPL OpenVPN for Android project and the Tunnelblick XOR patch fork.

Features targeted for this build:
- .ovpn import
- OpenVPN connection
- Tunnelblick `scramble obfuscate`
- OVPN30 launcher icon

The workflow pins the XOR engine to the v0.7.37-xor release and builds the universal debug APK.
